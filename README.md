# Cloudflare

Configuration checks for Cloudflare

## Install and run

```powershell
Install-MtPack merill/maester-pack-cloudflare
Connect-Maester
Invoke-Maester -Pack MERCF
```

This is a [Maester Pack](https://maester.dev/docs/packs). Its page is [packs.maester.cloud/p/mercf](https://packs.maester.cloud/p/mercf).
